# Jogo de Detetive - Resolução de Homicídio

## Requisitos do Projeto

- **Limite de tentativas:** Número máximo de tentativas para acusar por fase.
- **Personagem principal:** O detetive será o usuário, responsável por desvendar o caso.
- **Contexto inicial:** A história deve ser apresentada no código (introdução do cenário, vítima e suspeitos).
- **Coleta de pistas:** Gerar informações úteis que ajudem o usuário a descobrir quem matou. Exemplos: interrogar pessoas, visitar locais do crime, examinar evidências.
- **Descrição dos suspeitos:** Criar uma opção onde o usuário pode ver descrições físicas, personalidade e possíveis motivos de cada suspeito.
- **Acusação final:** Dar opção para o usuário acusar um suspeito.
- **Interrogação:** Permitir que o usuário escolha qual pessoa interrogar a cada rodada.
- **Conexão entre fases:** Conectar uma "árvore" (etapa/fase) à outra, mantendo a progressão lógica do caso.
- **Correção de erro ao acusar:** Arrumar o erro que ocorre quando o usuário tenta acusar alguém — o sistema deve validar corretamente a acusação sem falhas.


# Detective Game - Murder Mystery

## Project Requirements

- **Max attempts:** Maximum number of accusation attempts per phase.
- **Main character:** The detective will be the user, who must solve the case.
- **Initial context:** Provide the story setup directly in the code (introduction to the setting, victim, and suspects).
- **Clue generation:** Generate helpful information to assist the user in discovering who committed the murder. Examples: interrogating people, visiting crime scenes, examining evidence.
- **Suspect descriptions:** Create an option where the user can view physical descriptions, personality traits, and possible motives of each suspect.
- **Final accusation:** Give the user an option to accuse a suspect.
- **Interrogation:** Allow the user to choose which person to interrogate each round.
- **Phase connection:** Connect one "tree" (stage/phase) to another, maintaining logical case progression.
- **Fix accusation error:** Fix the error that occurs when the user tries to accuse someone — the system must properly validate the accusation without failures.
